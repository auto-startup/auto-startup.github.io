## 中文

**Auto Startup** 是一款免费的 AI 创业模拟网页游戏。

你将从黑客松开始，组建团队、确定创业方向，并在每一周面对市场新闻、团队争论、用户反馈和投资人提问。每个选择都会改变产品、炒作、进度、现金、理智、团队、声誉和用户信任，最终把公司带向 IPO、收购、现金耗尽、僵尸公司，或者更奇怪的结局。

- 浏览器直接运行，无需下载或注册
- 纯静态 HTML、CSS 和 JavaScript，无需后端
- 所有角色讨论均为预先编写，真实 AI Agent 调用次数为 0
- 支持中文和英文

### 本地运行

在本目录启动任意静态文件服务器，例如：

```bash
python3 -m http.server 8000
```

然后打开 [http://localhost:8000/](http://localhost:8000/)。

## English

**Auto Startup** is a free browser-based simulation game about building an AI startup.

Start at a hackathon, assemble a team, choose a direction, and survive weekly market news, team debates, user feedback, and investor questions. Every decision changes your product, hype, progress, cash, sanity, team, reputation, and user trust—eventually leading to an IPO, acquisition, runway failure, zombie company, or something stranger.

- Runs directly in the browser with no download or sign-up
- Fully static HTML, CSS, and JavaScript with no backend
- All character discussions are prewritten; actual AI agent calls: 0
- Available in Chinese and English

### Run locally

Start any static file server in this directory, for example:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000/](http://localhost:8000/).
